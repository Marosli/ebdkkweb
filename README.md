# E.B.D. Kežmarok — web

Statická stránka environmentálnej kancelárie E.B.D. Kežmarok (územné plánovanie, EIA/SEA, regionálne koncepcie).

- `index.html` — jediná stránka; hero výkres a mapa referencií sú inline SVG
- `css/site.css`, `js/site.js` — bez závislostí okrem Google Fonts (IBM Plex) a OSM embedu
- `img/` — fotografie z Wikimedia Commons (CC BY-SA), autori v `img/credits.json` a v pätičke
- Farebnosť výkresu: vyhláška ÚÚPV SR č. 153/2024 Z. z., príloha č. 2

Hostované cez GitHub Pages z vetvy `main`.
